# Changelog

## 0.1.0

- First public release of dynamic home-screen quick actions for iOS and Android.
- Includes the standalone example, typed errors and callback lifecycle protection.
- Adds collector-readable attribution to both distribution archives.
- See VALIDATION.md for tested environments and remaining qualification limits.

## 0.1.0-dev.1

- Initial independent DartNative quick-actions implementation.
- iOS FFI and Android FFI/JNI, dynamic shortcuts and activation delivery.
- Typed failures, serialized commands and protected async callback lifecycle.
- Standalone example and behavioural tests; see VALIDATION.md for evidence limits.
